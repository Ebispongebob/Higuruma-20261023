# 08：审核页面与报告

## 目标与依据

依据 [milestone](../milestone.md) 与 [structure](../structure.md)，完成审核页面与报告。对应 M3。

## 依赖与提交边界

前置任务：07。本任务独立形成一次本地提交，不合并其他任务的实现。任务文件初次建立统一提交。

## 范围

提供 ChatGPT 式侧栏、历史记录、主工作区和上传输入区；接入规则管理、模型配置、审核进度、原文引用及模板报告。

## 交付与验收

浏览器完成导入制度、确认规则、上传文件、审核、查看报告、人工复核和历史回看；桌面与窄屏可用。报告包含制度、模型与审核配置版本，全部不适用或未决不能输出通过。

交付代码或材料及必要说明；测试仅使用完整业务入口的端到端测试，不写单元测试。不得伪造外部服务结果、人工标注或业务确认。未经额外授权不得部署、远推。不得在文件、日志或响应中写入明文凭据。

建议提交信息：`实现：审核页面与报告`。

页面需要支持 Agent 创建、切换与配置；新增 Agent 不继承其他 Agent 的私有规则或审核记录。

## 当前结果

页面与 API 已实现；API 端到端及 11 项真实浏览器端到端检查通过。桌面和手机布局均已截图复核。参见 `reports/validation.md`。
