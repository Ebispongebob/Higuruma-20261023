# 01：准备采购审核样例

## 目标与依据

依据 [milestone](../milestone.md) 与 [structure](../structure.md)，完成准备采购审核样例。对应 M1。

## 依赖与提交边界

前置任务：无。本任务独立形成一次本地提交，不合并其他任务的实现。任务文件初次建立统一提交。

## 范围

确定采购场景，提供制度原文、调试样例和期望结论；真实人工标注与程序演示材料明确区分。

## 交付与验收

提供 20 组模型验证样例；独立验收材料不用于提示调整。缺少真实材料时记录缺口，不伪称人工确认。

交付代码或材料及必要说明；测试仅使用完整业务入口的端到端测试，不写单元测试。不得伪造外部服务结果、人工标注或业务确认。未经额外授权不得部署、远推。不得在文件、日志或响应中写入明文凭据。

建议提交信息：`实现：准备采购审核样例`。
