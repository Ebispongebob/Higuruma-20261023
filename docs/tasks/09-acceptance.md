# 09：端到端验收与效果评估

## 目标与依据

依据 [milestone](../milestone.md) 与 [structure](../structure.md)，完成端到端验收与效果评估。对应 M4。

## 依赖与提交边界

前置任务：08。本任务独立形成一次本地提交，不合并其他任务的实现。任务文件初次建立统一提交。

## 范围

仅编写端到端测试，不写单元测试；真实服务覆盖 T01～T12 及两种模型接入，生成可复查结果。

## 交付与验收

按 milestone 检查全链路；独立验收需至少 30 份文件和 100 条人工标注，违规召回率至少 95%，误报率不高于 10%；单列证据不足率及自动覆盖率。缺少材料或外部服务时明确未完成，不替换为模拟通过。

交付代码或材料及必要说明；测试仅使用完整业务入口的端到端测试，不写单元测试。不得伪造外部服务结果、人工标注或业务确认。未经额外授权不得部署、远推。不得在文件、日志或响应中写入明文凭据。

建议提交信息：`实现：端到端验收与效果评估`。
