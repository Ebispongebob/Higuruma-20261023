# 03：文件解析与原文定位

## 目标与依据

依据 [milestone](../milestone.md) 与 [structure](../structure.md)，完成文件解析与原文定位。对应 M2、M3。

## 依赖与提交边界

前置任务：02。本任务独立形成一次本地提交，不合并其他任务的实现。任务文件初次建立统一提交。

## 范围

支持文本 PDF、DOCX、TXT，提取段落及表格，保留页码或段落位置，保存原始文件和解析结果。

## 交付与验收

从上传 API 验证三种格式；扫描件、损坏、超限或不完整解析明确失败，不静默截断。

交付代码或材料及必要说明；测试仅使用完整业务入口的端到端测试，不写单元测试。不得伪造外部服务结果、人工标注或业务确认。未经额外授权不得部署、远推。不得在文件、日志或响应中写入明文凭据。

建议提交信息：`实现：文件解析与原文定位`。

已通过 TXT、PDF 跨页、DOCX 表格和解析异常的业务端到端检查。参见 `reports/validation.md`。
