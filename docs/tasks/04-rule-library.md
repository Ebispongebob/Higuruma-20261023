# 04：制度和规则版本管理

## 目标与依据

依据 [milestone](../milestone.md) 与 [structure](../structure.md)，完成制度和规则版本管理。对应 M2。

## 依赖与提交边界

前置任务：03。本任务独立形成一次本地提交，不合并其他任务的实现。任务文件初次建立统一提交。

## 范围

支持制度上传、手工录入及确认规则；记录制度原文位置、版本、适用范围、有效日期、例外和所需证据。

## 交付与验收

按业务日期选定有效版本；只审核已确认规则。目标为 30～50 条人工确认规则；演示规则不可标为真实业务标准。

交付代码或材料及必要说明；测试仅使用完整业务入口的端到端测试，不写单元测试。不得伪造外部服务结果、人工标注或业务确认。未经额外授权不得部署、远推。不得在文件、日志或响应中写入明文凭据。

建议提交信息：`实现：制度和规则版本管理`。

## 多 Agent 范围补充

允许创建多个审核 Agent，各自拥有制度、规则、模型配置和审核记录。以 chinese-law-corpus 建立劳动合同演示 Agent，保留法条来源和版本，验证 Agent 间的数据隔离。

## 当前结果

已支持多 Agent 隔离、规则版本和来源校验；已导入 30 条劳动合同演示规则，业务人工确认未完成。参见 `reports/validation.md`。
